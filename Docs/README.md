# Docs

System-wide knowledge: how this machine is set up and tooling facts that matter in any project. Repo-specific knowledge lives as project skills in each repo (`<repo>/.omp/skills/`), not here.

- [auth-keyring/](auth-keyring/README.md) - GPG fingerprint gating, GNOME keyring autologin, passkeys, sudo/ssh auth
- [git/](git/README.md) - hooks, push signing, branches/history, dotfiles bare repo (`dotfiles autoadd`, standards, Docs structure), shims, GitHub/GitLab CI
- [hyprland/](hyprland/README.md) - polkit, launching apps, keybindings, scaling/toggles
- [quickshell/](quickshell/README.md) - QML animation, notifications plugin, indicators, omacale shell
- [omarchy/](omarchy/README.md) - input, themes, plugins, apps, Zen, Cider, wallpapers
- [linux/](linux/README.md) - phones/media, networking, power/hardware, systemd, local AI, USB, VPS, dev tools
- [wine/](wine/README.md) - Electron/WebView2 apps under Wine, tracing, prefix/MSI, native app installs
- [virtualization/](virtualization/README.md) - libvirt, QEMU anti-detection, mitm capture, Windows guests, RE, crash diagnosis
- [omp/](omp/README.md) - extensions, sessions/config, commits/hooks, skills and AGENTS.md
- [tools-mcp/](tools-mcp/README.md) - FilmCraft/PhotoCraft, GitHub MCP, web interface guidelines
- [web-stack/](web-stack/README.md) - bun monorepos, docker compose, prisma, zitadel, shadcn/Tailwind, python testing
- [latex/](latex/README.md) - LaTeX gotchas, study guides and proof packets
- [ml/](ml/README.md) - generic PyTorch/LM training facts
- [reverse-engineering/](reverse-engineering/README.md) - web scraping and client-JS obfuscation
- [misc/](misc/README.md) - one-off reusable facts
